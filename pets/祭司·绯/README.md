# 祭司·绯

红发、黑色弯角与十字纽扣眼，留在黑白裙装的修长玩偶轮廓里。抬手招呼和屈膝跃起，让她从静止的展示姿态走到桌面上。

本次发布为 2026-10-03 确认的跳跃与打招呼修正版。九组动作与十六向注视均包含在 v2 图集中。

## 文件与安装

- `pet.json`：独立 ID `priestess-fei`，运行时使用无损 WebP
- `spritesheet.png`：最终 PNG 原样保存
- `spritesheet.webp`：解码后的 RGBA 像素与 PNG 完全一致
- `layout.json`：1536×2288、8列×11行、每格192×208，73有效帧

将本文件夹放入 `$CODEX_HOME/pets/`（未设置时为 `~/.codex/pets/`），重启支持 v2 自定义宠物的 Codex 桌面客户端。不要覆盖其他宠物文件夹。

最终图集已保存到 ChatGPT Work Pets；本地安装包未在所有 Codex 客户端版本测试。GIF 和 MP4 仅作预览，其时长不代表所有客户端的播放策略。

制作与整理：[YinL-k](https://github.com/YinL-k)，AI 辅助制作。角色与时装原始设计属于网易游戏《第五人格》。详见 [NOTICE.md](NOTICE.md)。
