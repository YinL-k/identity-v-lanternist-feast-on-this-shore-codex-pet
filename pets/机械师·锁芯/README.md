# 机械师·锁芯

> 齿轮可以校准时间；人心却没有一张足够精确的装配图。

特蕾西·列兹尼克在钟表店与工作室里长大。她擅长把问题拆成零件：误差可以测量，机关可以拆解，线路可以重接。父亲留下的爱、那场改变一切的事故、债务与尚未完成的发明，却让她面对一种不能只靠工具修好的缺口。

「锁芯」把这种矛盾变成一件可以看见的东西：黑色的锁扣在外，曾经发热的机芯被压在更深处。紫晶与机械结构让她像一件精密装置，但装置内部并没有真正归于静止。

标准版保留纤长比例、紫晶锁瞳与非对称机械臂，更强调“人形机械装置”的冷静轮廓。

将完整文件夹放入 `$CODEX_HOME/pets/`，重启后选择「机械师·锁芯」。详见 `NOTICE.md`。
