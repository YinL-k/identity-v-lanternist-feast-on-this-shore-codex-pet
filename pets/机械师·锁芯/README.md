# 机械师·锁芯

《第五人格》机械师「锁芯」的非官方同人动画桌宠，使用 AI 辅助制作。

- 角色与时装原始设计：网易游戏《第五人格》
- 桌宠制作与整理：[YinL-k](https://github.com/YinL-k)
- 运行时配置：`pet.json`，图集格式为 v2
- 运行时图集：`spritesheet.webp`，同时保留像素一致的原始 `spritesheet.png`
- 规格：1536 × 2288、每格 192 × 208、9 组动作与 16 个注视方向，共 73 帧

将这个完整文件夹放入 `$CODEX_HOME/pets/`（默认 `~/.codex/pets/`），重启支持本地 v2 宠物的 Codex 桌面客户端后，在宠物选择界面选用。`layout.json` 仅说明图集布局，不是客户端安装配置。

与其他版本使用不同的 `id`，可并存。具体安装说明见仓库首页；本包尚未逐一测试所有客户端版本。使用限制见 `NOTICE.md`。

本次图集来自用户指定的 ChatGPT Work 宠物「机械师·锁芯」，原始图集未作动作修改。已验证图集结构和 PNG/WebP 像素一致性，尚未在本地客户端实测安装。
