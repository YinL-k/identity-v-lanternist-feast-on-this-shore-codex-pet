# 舞女·钟阁杼思

> 当机杼声停下，下一步才真正属于她自己。

玛格丽莎·泽莱熟悉舞台、华服与被注视，也熟悉“自由”不总像想象中那么轻盈。她曾不断换名字、换生活、换去处，希望每一次改变都能把过去甩得更远一些；可真正属于自己的方向，始终要由她亲自迈出去。

「钟阁杼思」把她放进一座精密的时间装置。其灵感来自铜镀金乡村景色水法钟：纺车、帆船、流水、花木与钟表机构在固定节律里循环。时装真正动人的地方却在“停止”——当机杼声不再替她规定节奏，舞台便从展示她的地方，变成她主动走向的地方。

原版保留冰蓝、鎏金、钟表结构与纤长瓷偶般的比例。

将完整文件夹放入 `$CODEX_HOME/pets/`，重启后选择「舞女·钟阁杼思」。详见 `NOTICE.md`。
