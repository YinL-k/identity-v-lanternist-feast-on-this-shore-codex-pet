# 幻灯师·于此岸赴宴

> 她把“彼岸”留给传说，只把眼前这一刻攥在手里。

阿曼达·加蒂斯很早就知道，眼睛看见的东西未必可靠，时间也未必会按顺序抵达。睡意、幻觉与骤然缺失的片段切开了她的成长；光学装置则给了她另一种观察世界的方法——把稍纵即逝的东西定格下来，再决定自己愿意相信什么。

「于此岸赴宴」把这种选择变得更锋利。她不再向遥远的幸福仰望，而是把青鸟、伤痕、利爪和机械残骸都拖回现实。与其等待一个完美的彼岸，不如先让此岸热闹起来。
