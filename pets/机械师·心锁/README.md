# 机械师·心锁

护目镜礼帽、金色纽扣眼与红金外套，收在修长人偶的轮廓里。她握着心锁点头、跃起，深蓝裙摆与靴子一同落回桌面。

本次发布为 2026-10-03 确认的跳跃头部动作及鞋款一致性修正版。心锁为独立桌宠，不覆盖锁芯。包含九组动作及十六向注视。

## 安装与验证

将完整文件夹放入 `$CODEX_HOME/pets/`，未设置时为 `~/.codex/pets/`，重启支持 v2 自定义宠物的 Codex 桌面客户端。配置 ID 为 `mechanic-heartlock`。

最终 PNG 原样保存；无损 WebP 解码后的 RGBA 与 PNG 完全一致。图集为1536×2288、8列×11行、每格192×208，73有效帧，其余15格透明。`layout.json` 说明图集布局。

最终图集已保存到 ChatGPT Work Pets；本地安装包未在所有 Codex 客户端版本测试。GIF 和 MP4 为动作预览，时长不代表实际客户端播放策略。

制作与整理：[YinL-k](https://github.com/YinL-k)，使用 AI 辅助制作。角色与时装原始设计属于网易游戏《第五人格》。文案为非官方二次创作。详见 [NOTICE.md](NOTICE.md)。
